# 1.0.0

- First release.
- Replace any object ID with a captured selection of one or more objects.
- Replacement inherits position, rotation, scale, flips, groups, colors and layers.
- Works in every level with no level editing required.
- Optional editor-side application, so replacements can be baked into a level.
- Menu in the editor's top bar and on the F5 keybind.
